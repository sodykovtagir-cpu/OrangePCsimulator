# Игровые администраторы

Откройте `admin.php?tab=accounts` и войдите обычным паролем веб-админки.
Вкладка **«Аккаунты / админы»** позволяет назначать и снимать роль у подтверждённых аккаунтов.

- Роли хранятся отдельно от аккаунтов в `game_admins.json`, по неизменяемому ID пользователя.
- Имена Goose/Semyalol не зашиты в клиент: совпадение ника само по себе ничего не даёт.
- `account.php` возвращает `is_admin` при входе, подтверждении и запросе профиля.
- `api.php` возвращает `author_is_admin` по ID владельца публикации, а не по присланной строке автора.
- В игре роль доступна как `ServerAccounts.IsAdmin`; сейчас она даёт красный ник в профиле и мастерской.
- Роль обновляется при новом входе/обновлении профиля. Изменения списка не требуют новой сборки игры.
- Для будущих привилегированных сетевых действий всегда проверяйте роль по токену на сервере. Локальный кэш предназначен для интерфейса, не для авторизации.
- Игровая роль не меняет пароль/доступ к веб-админке и не начисляет деньги.

На новом сервере создайте конфигурацию по `game_admins.example.json` или назначьте пользователей через админку. Боевой `game_admins.json` не входит в git.
