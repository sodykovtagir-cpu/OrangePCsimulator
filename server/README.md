# Remote Quiz — админка сайта → игра

Позволяет с админ-панели на сайте отправить квиз в игру (Orange PC Simulator):
игра периодически опрашивает сервер, и когда админ «отправляет» квиз, ближайший
опрос забирает его и показывает диалог с Title/Body и кнопкой **Yes**, которая
открывает ссылку.

## Как это работает

```
Админ (admin_quiz.php) → пишет quiz_pending.json
Игра (каждые 45 сек)  → GET api.php?action=quiz&i=1
                       → сервер одноразово отдаёт квиз и очищает файл
                       → игра показывает диалог (Quiz.TriggerRemote)
```

Квиз одноразовый: пока игра его не забрала, он ждёт в `quiz_pending.json`.
Если игроков несколько — заберёт первый опросивший.

## Установка на хостинге (byethost)

1. Залейте `admin_quiz.php` в **ту же папку**, где лежит `api.php` мастерской.
2. Откройте `admin_quiz.php` в браузере → войдите.
   Пароль по умолчанию **`admin123`** — обязательно поменяйте в файле
   (строка `$ADMIN_PASSWORD = 'admin123';`).
3. Добавьте блок из `api_quiz_snippet.php` в `api.php` (новый `action=quiz`).
4. Убедитесь, что в папке можно создавать файлы (byethost обычно разрешает;
   при ошибке записи админка покажет сообщение).

## Клиентская часть

В игре опрос уже реализован (Quiz.cs → WorkshopClient.GetQuiz).
По умолчанию опрос каждые **45 секунд**; настраивается в инспекторе
на объекте Quiz (поле `pollInterval`). Первый опрос — через 3 секунды после старта.

## Поля квиза

| Поле  | Обязательно | Назначение |
|-------|-------------|------------|
| link  | да          | ссылка, которую откроет кнопка Yes |
| title | нет         | заголовок диалога (подставляется в Title) |
| body  | нет         | текст диалога (подставляется в Body) |
