# Серверы в магазине

База — пользовательский `ed3df93` (новые ServerCPU/ServerFan, изменённые Server/Server ATX, текстуры RMD). Сцены и авторские модели/UV/масштабы не менялись.

## Каталог

Добавлено **21 товар комплектующих** в существующие вкладки, без удаления или перестановки прежних товаров:

- **Case:** Server — 350; запасная Server Cover — 40. Корпус включает крышку и 4 пустые съёмные корзины. Удалённый пользователем демонстрационный HDD не возвращается.
- **Processor:** 7 серверных RMD, включая исходный 3960X; настольный 7950X остаётся отдельным товаром.
- **Motherboard:** Server ATX — 650; 2 CPU, 14 DIMM, 2 кулера.
- **Power Supply:** тонкий серверный БП 2000 W — 350. Старое имя ресурса PSUThin_2000kW сохранено для совместимости.
- **Cooler:** ServerCooler — 85, Pro — 110, Max — 145. Варианты используют авторский ServerFan, отличаются охлаждением/потреблением, а не выдуманными мешами.
- **Memory:** Server ECC 32/64/128 GB — 420/840/1680.
- **Storage:** запасная корзина — 25; Enterprise HDD 8/16/20 TB — 230/410/540.

ECC — название линейки в текущей симуляции; отдельный алгоритм исправления ошибок памяти/RAID не реализовывался. Оперативная память и диски используют существующие реальные игровые параметры capacity/score/wattage/health. Варианты основаны на существующих моделях, а не на новых процедурных примитивах.

## Вкладка «Готовые серверы»

Добавлена страница `Ready Server`, переведённая на все 42 языка таблицы локализации. Конфигурации — **полные префабы**, непосредственно содержащие корпус, плату, БП, CPU, кулеры, RAM и HDD. Они не используют ReadyBuildSpawner и не создают второй корпус через Instantiate.

| Сервер | CPU | RAM | HDD | Цена деталей | Цена готового |
|---|---|---|---|---:|---:|
| Orange Rack S1 | 1×1920X | 2×32 = 64 GB | 2×2 TB | 3285 | 3615 |
| Orange Rack Storage | 1×3960X | 4×32 = 128 GB | 4×8 TB | 5285 | 5815 |
| Orange Rack Compute | 2×3970X | 8×64 = 512 GB | 2×16 TB | 12510 | 13765 |
| Orange Rack Ultra | 2×PRO 5995WX | 14×128 = 1792 GB | 4×20 TB | 33920 | 37315 |

Каждый включает БП 2000 W, крышку, все 4 съёмные корзины и PCOS с Info, Disk, Downloader, Browser и Benchmark на одном системном диске. Остальные диски пустые. Lua Editor автоматически не устанавливается.

Все части заранее находятся на авторских insertPos внутри префаба. Дополнительный массив `ServerChassis.factoryParts` только подключает **уже существующие** Item к слотам, создавая штатные связи TryAttach. В ServerChassis нет Instantiate/AddComponent/ExecuteInEditMode. При восстановлении .opc заводские части удаляются до Start, потому что SaveManager восстанавливает снятые/установленные Item самостоятельно. Это сохраняет разборку, содержимое дисков и правило HDD→корзина→корпус без лишних копий.

## Экономика

Ориентиры взяты из текущего Shop.asset: 7950X — 800, EXATX — 400, MSG ATX — 520, большая майнерская рама — 500, БП 2000 W — 300, RAM 32/64 GB — 380/760, HDD 8/16/20 TB — 190/340/450.

Серверная память/диски имеют умеренную наценку; CPU масштабируются по игровому score. Для готовых серверов используется правило существующего генератора ПК: **сумма всех входящих товаров + 10%, округление вверх до 5**. Стоимость крышки/4 корзин уже включена в 350 за корпус и второй раз не прибавляется. Новые товары не требуют Bitcoin. Полный состав с fileID слотов и расчётом цены: `tools/server_catalog_manifest.json`.

## Изображения и исправления при проверке

- Пользовательский `Assets/Texture2D/RmdServer.png` используется как общий магазинный спрайт всех RMD-процессоров, включая существующий 7950X. PNG не изменён. UV-текстура RMDThreadthripper не подменяется магазинной иконкой.
- Для корпуса, платы, БП, крышки, корзины, кулера, памяти и HDD сделаны 8 настоящих Blender Cycles-рендеров из игровых мешей, UV и материалов: 256×256, непрозрачный белый фон, единый ортографический ракурс. Одинаковые физические варианты делят одну обложку. Готовые серверы имеют одинаковый внешний корпус и используют его обложку; конфигурация указана в карточке.
- Для кулера учтены авторские prefab overrides лопастей (rotation/scale) и проектные текстуры вместо сохранённых в FBX Windows-путей; проверено отсутствие розовых missing-texture материалов.
- Все 8 изображений визуально просмотрены вместе; автоматически проверены границы, отсутствие пустых/обрезанных кадров, размер, alpha, GUID спрайтов и SHA256 исходных мешей/материалов/текстур.
- У ServerCooler добавлены отсутствовавший корневой тег Cooler и корневой триггер для ручной установки. Авторские твёрдые дочерние коллайдеры и FanSpin сохранены.
- Посадочная точка **второго** кулера приведена к уже настроенной пользователем первой: прежде второй кулер находился на 0.574 от CPU, теперь совпадает по высоте с его посадкой. Геометрия/масштаб платы и кулера не менялись.
- Старая отдельная модель `Resources/components/Server.fbx`, конфликтовавшая именем с игровым Server.prefab, перенесена в `Models/LegacyServer.fbx`. Её GUID сохранён, ссылка на меш в BigMiner остаётся действительной. Новая авторская Models/Server.fbx не менялась.

## Воспроизведение и проверки

```bash
python3 tools/generate_server_catalog.py
python3 tools/export_server_cover_scenes.py
blender -b -t 4 --python-exit-code 1 -P tools/render_server_covers.py -- --root .
python3 tools/finalize_server_covers.py
python3 tools/test_server_catalog.py
python3 tools/test_server_trays.py
```

Генератор идемпотентен; не запускает старый генератор ПК/майнеров и не перезаписывает их конфигурации. Для Python нужны PyYAML, NumPy, Pillow; для поведенческих C#-проверок — Mono/mcs.

Проверены все товары/ссылки, сохранение прежних страниц, socket/tag/коллайдеры, отсутствие второго Rigidbody, полный заранее вложенный состав 4 префабов, охлаждение обоих CPU, достаточная мощность БП, одна PCOS на сборку, вместимость дисков, точная сумма RAM, цены и обложки. Настоящий ServerChassis с factoryParts исполняется в Mono с минимальными engine doubles: проверяются подключение готовых вложенных компонентов и удаление заводских копий при загрузке.

Прошли также test_physical_cables.py, test_boot_debug.py, test_overclock_boot.py, test_grid_assembly_motion.py, test_wired_case_drag.py, test_filament_covers.py. Общий test_localization.py уже падает на исходном ed3df93 из-за пустого украинского перевода старого ключа «3D Printer»; новая строка Ready Server заполнена на всех языках.

**Полная компиляция проекта и PlayMode не выполнялись: Unity Editor в среде отсутствует.** После импорта в Unity проверить: покупку отдельных товаров и всех 4 сборок; ручную установку ServerCooler; старт PCOS/видеокабель; снятие/возврат корзин; сохранение/перезагрузку как готовой, так и частично разобранной сборки. Геометрия каждой готовой сборки должна быть видна уже при перетаскивании префаба в сцену без Play Mode.
