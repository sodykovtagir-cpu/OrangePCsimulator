# Выкат хостинга сайтов на Byethost (FTP)

## Что и куда

FTP: `ftpupload.net`, пользователь `b4_42712522` (пароль — в панели Byethost,
в репозиторий его не кладём).
Каталог сайта: `/htdocs/`.

| Файл из репозитория | Куда на сервере | Обязательно |
| --- | --- | --- |
| `Hosting/sites/lib.php` | `/htdocs/sites/lib.php` | да, всегда вместе с `api.php` |
| `Hosting/sites/api.php` | `/htdocs/sites/api.php` | да, всегда вместе с `lib.php` |
| `Hosting/sites/reserved.json` | `/htdocs/sites/reserved.json` | только если менялись зарезервированные домены |
| `Hosting/sites/.htaccess`, `.user.ini`, `data/.htaccess` | `/htdocs/sites/…` | один раз при первой установке |
| `server/sites_admin.php`, `server/sites_preview.php`, `server/sites_preview.js` | `/htdocs/workshop/…` | если менялась админка |

**Никогда не заменяй** `/htdocs/workshop/users.json`, `config.php`,
`admin_config.json`, `game_admins.json`, `account.php`, `/htdocs/sites/data/*` —
там аккаунты и данные игроков.

## Порядок

1. Скачай текущие `lib.php` и `api.php` в отдельную папку (бэкап).
2. Залей новые `lib.php` и `api.php` **парой**: версии должны совпадать, иначе
   новый `api.php` позовёт функции, которых нет в старом `lib.php`.
3. Права на файлы — обычные `644`, ничего исполняемого не нужно.
4. `data/` должна оставаться доступной для записи (её создаёт сам `api.php` при
   первом запросе, если её нет).

Через lftp:

```bash
lftp -u 'b4_42712522,ПАРОЛЬ' ftpupload.net -e "
  cd /htdocs/sites;
  put Hosting/sites/lib.php -o lib.php;
  put Hosting/sites/api.php -o api.php;
  cls -l lib.php api.php; bye"
```

## Проверка после выката

Byethost сначала отдаёт JS-челлендж (`aes.js`/`toNumbers`) — это нормально, игра
проходит его сама. Проверяй запросами с уже полученной cookie `__test`:

- `health` → `{"ok":true,"service":"orange-sites","version":1,...}`;
- `list` → JSON со списком сайтов (не HTML);
- `stats`/`publish`/`topup`/`local` без токена → **401** (действие распознано,
  нужен вход);
- неизвестное действие → **404 `Unknown action`**;
- `https://…/sites/data/state.php`, `/sites/lib.php` → **403**.

Если `topup`/`local` отвечают `Unknown action`, значит на сервере всё ещё старый
`api.php` (именно это и давало ошибку в игре).

## Изменения модели в v3 (кошелёк)

- Деньги игры больше не расходуются фоновыми запросами: только `action=topup`
  переносит $100 из баланса в кошелёк хостинга.
- Аренда = $100 / 1800 с за работу сайта + $20 / 1800 с реального обслуживания
  (открытая сессия или скачивание). Свой домен — $1100 / 1800 с и $1000 разово.
- Публикация бесплатна; при отсутствии кошелька сайт просто стоит на паузе.
- После выката существующие сайты остаются активными, но кошелёк у них может быть
  пустым: первый запрос от игры покажет «пополни кошелёк».

## Данные, которые переносятся автоматически

При первом запросе после обновления старые записи переводятся на посекундную
аренду: ретроактивного долга нет, остаток уже оплаченного периода сохраняется
как предоплаченные секунды (`credit`), простой в прошлом не пересчитывается.
Счётчики кошелька (`wallets[owner:world].ceiling`) остаются прежними.

## Чего нельзя делать

- Не заливать `lib.php` без `api.php` и наоборот.
- Не удалять `/htdocs/sites/data/` — это все публикации.
- Не держать `config.php`, пароли FTP/MySQL и `users.json` в репозитории.
