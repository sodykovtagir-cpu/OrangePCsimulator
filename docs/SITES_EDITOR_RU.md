# Сайты игроков — этап 1: редактор, пакет, renderer, Lua

## Согласованная цель всей функции

- Игровые серверы служат хостами сайтов, которые доступны **всем игрокам** через настоящий backend и поиск Oggle.
- Опубликованный сайт остаётся доступен после выхода владельца из игры.
- Оплата по **реальному времени**, срок идёт и вне игры. **Сумма и длительность периода пока не заданы пользователем.** Не устанавливать выдуманный тариф и не списывать деньги до согласования.
- Пользовательский игровой URL — доплата **$1000**. Это не регистрация настоящего интернет-домена.
- Редактор визуальный, как холст Scratch; обработчики — текстовый Lua, не блочный редактор программирования.
- Button / Text / Image, правый инспектор (имя, координаты, размер, pivot, оформление, текст, шрифт, OnClick), удержание текста для ввода.
- В пакете название, описание, ключевые слова, иконка и все импортированные файлы из виртуального корня сайта. Браузер рендерит свой формат, не HTML. Получение сайта должно учитывать реальную загрузку и игровой интернет.

## Что сделано в этом этапе

В App Downloader добавлен **Site Editor / Редактор сайтов**, ассоциация `.osite`. Из Text Editor переиспользовано только нативное оформление окна и существующая иконка; сам Text Editor и его префаб не изменены. Рабочее поле строится из UGUI-компонентов: сверху Open/Save/Undo/Redo/Preview/Host, слева палитра, по центру холст, справа прокручиваемый инспектор.

- Создание, выделение, перетаскивание, удаление Button/Text/Image.
- Имя, ID, X/Y, ширина/высота, pivot X/Y у каждого элемента, пресеты top-left/center. Координаты и pivot заданы от верхнего левого угла страницы; (0,0) — top-left, (.5,.5) — center. Позиция обозначает точку pivot.
- Текст, цвет, размер и три стандартных шрифта (Roboto, Roboto Medium, моноширинный из существующих ресурсов проекта). Для button/image — цвет заливки или импортированная PNG/JPEG/PIC-картинка. Цвет вводится в HEX `#RRGGBB` или `#RRGGBBAA`.
- Удержание текста 0.55 сек. включает inline InputField на самом холсте. Drag сохраняется как одна операция undo.
- Настройки проекта: title/description/keywords, размер страницы, фон, импорт иконки и управление файлами корня. Импортированные данные находятся внутри `.osite`, внешние пути не сохраняются.
- Сохранение и открытие через штатные PCOS-диалоги. Файл использует существующий механизм хранения/сохранения игры. New требует повторного нажатия, если проект непустой.
- Транзакционный Undo/Redo: недопустимые изменения отклоняются без порчи проекта. Общий бюджет истории — 16 MiB, до 40 снимков.
- Preview использует копию документа: Lua не изменяет авторский проект; перенаправления и скачивания только показываются в строке состояния, не исполняются вне редактора.

**Кнопка Host пока не публикует сайт.** Она сообщает об этом явно; отсутствуют ложный успех, HTTP-запросы или списания. Отдельная программа хостинга, серверная публикация, привязка к железу, оплаченные сроки, пользовательские URL, поиск/скачивание Oggle ещё НЕ реализованы. Этот коммит — первый этап, не выпуск всей запрошенной функции. Существующий Browser не менялся.

## Формат и ограничения первой версии

JSON `format: "orange-site"`, `version: 1`; элемент имеет стабильный ID, kind (`button`, `text`, `image`), геометрию, оформление, текст и onClick. assets — плоский виртуальный корень с `name`, MIME/media, base64 data. Это не Unity prefab и не сериализация произвольных CLR-типов.

- Пакет до 8 MiB UTF-8, глубина JSON до 32, до 256 элементов, до 64 файлов.
- Файл до 2 MiB, суммарно до 6 MiB декодированных данных; картинки до 2048 x 2048 и суммарно до 8 мегапикселей. До LoadImage проверяется заголовок/размер, после — успешное декодирование. Эти технические предохранители не являются согласованными тарифами/лимитами серверного железа.
- Имена файлов только в корне; без `/`, `\\`, `..`, URL и абсолютных путей. MIME whitelist: PNG/JPEG и `application/x-pcos-file` (содержимое **игрового** файла). Исполнять скачанный файл автоматически запрещено.
- Пакет проверяется при чтении, записи, изменениях и перед рендером. Текст не обрабатывается как rich text или HTML. Нет внешних шрифтов и изображений.

## Lua сайта

Пример OnClick:

```lua
RedirectURL("www.modforge.com")
```

Другой обработчик:

```lua
SetText("heading", "Готово!")
Alert(GetText("heading"))
StartDownload("site/myapp.exe")
```

Доступны `RedirectURL(url)`, `StartDownload("site/file")`, `Alert(text)`, `SetText(id,text)`, `GetText(id)`, `SetVisible(id,bool)` и базовые возможности интерпретатора. Аргументы-строки требуют кавычек. Ссылка — только адрес внутри игрового браузера, не реальный HTTP-запрос и не запуск внешнего браузера. Download — событие для браузера; последующая интеграция обязана потребовать согласие посетителя и штатный диалог записи, без автозапуска.

Используется существующий PcosLua, но **не вызываются PcosLuaHost.Bind/LuaUi/LuaGfx**. Нет API `os`, `fs`, `admin`, `pc`, `terminal`, `io`, `require` и сетевого API. Удалены потенциально дорогие стандартные `string`, `table`, `pcall` из VM сайтов. На обработчик: 256 токенов, 5000 операций, глубина вызовов 32, строки конкатенации до 8192, до 32 UI/навигационных действий. Обработчики запускаются только по клику; нет autoplay/update.

В общем интерпретаторе добавлены необязательные лимиты, значения прежних приложений не изменены. Заодно переменная библиотеки table переименована без смены логики: прежнее имя конфликтовало с локальными переменными лямбд при компиляции Mono.

Затем проверить сейв/загрузку всей игры. Нельзя заявлять визуальную и end-to-end проверку выполненной.

## Следующий этап

1. Уточнить сумму и реальный период оплаты; правила продления/неоплаты и ограничения железа без выдуманных цен.
2. Отдельный Site Host с выбором игрового сервера/проекта, URL, иконки и метаданных. Подтверждение цены до отправки/списаний.
3. Backend с авторизацией владельца, строгой повторной валидацией пакета, атомарной записью, уникальностью URL/резервированием системных адресов, реальными UTC-сроками аренды, обновлением/удалением и модерацией. Нельзя доверять клиентскому expiry/цене и нельзя выполнять Lua на backend.
4. Oggle: поиск по метаданным, загрузка конкретной оплаченной ревизии, учёт трафика/задержки через InternetService, отмена запросов и устаревших ответов при навигации/выключении, рендер через SiteCanvas. Клик RedirectURL должен идти через Browser, а не Unity Application.OpenURL.
5. Настоящие скачивания только из корня пакета: пользовательское подтверждение, безопасный SaveDialog, отсутствие автозапуска/доступа к System/.
