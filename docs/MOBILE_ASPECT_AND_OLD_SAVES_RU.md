# Пропорции мобильного превью и чтение больших сохранений

## Исправления управления

- В Menu настройки управления были на world-space Canvas 840×500, независимо от пропорций телефона. Превью теперь имеет логические размеры игрового HUD (CanvasScaler Expand, reference 800×500) и пропорции текущего Screen.width / Screen.height. В оболочку меню оно вписывается равномерным масштабом; это не растяжение иконок по одной оси.
- controlsRoot ссылается на сам PreviewMobileControlsPanel. Панель стрелок сетки теперь тоже создаётся внутри этого viewport, а не в соседней области другого размера.
- В превью хотбара отсутствовала восьмая кнопка Grid. Добавлена её визуальная копия без игровых callbacks; размеры детей и правила HorizontalLayoutGroup/ContentSizeFitter соответствуют Main. Габариты хотбара больше не отличаются из-за семи кнопок против восьми.
- MobileAdaptiveSlidePanel измеряет повёрнутый RectTransform через GetWorldCorners в координатах viewport. Исходный localScale запоминается один раз; fit вычисляется заново от него, без накопительного уменьшения.
- При нехватке длины на боковом краю уменьшается весь хотбар, включая кнопки и фон. Открытая панель ограничивается по обеим осям, в том числе в углах. Отступ edgePadding (8 логических единиц) сохранён. Закрытая позиция рассчитывается от открытой и фактической толщины.
- Перенос из координат viewport в anchoredPosition учитывает фактического родителя. Для вложенного Functions/Panel не предполагается, что Mobile и Functions — один RectTransform.
- Изменение размеров области/панели и режима редактирования вызывает повторную подгонку. Каждый неподвижный кадр больше не вызывает Canvas.ForceUpdateCanvases и ForceRebuildLayoutImmediate. Во время реального изменения перестраивается только хотбар.
- Ключи PlayerPrefs, привязка к краям/углам, сохранение/отмена/reset и прежняя миграция Animator/DoAnimation не удалены.

## Что установлено по сохранениям

Пользовательский файл недоступен: он больше 25 МБ и не загружается как на телефоне, так и на ПК. Причина именно этого отказа **не подтверждена**.

В истории форматов эпохи Device Manager/Remote Desk и текущем коде XOR и HMAC совпадают. Признаков смены ключа не найдено; обход подписи не добавлялся.

Выявлен и воспроизведён другой реальный дефект: DecodeHeader для **OPC3** отклонял заголовок GameData длиннее 8 МиБ, хотя подпись была правильной и полный Decode того же файла проходил. GameData может содержать целый второй мир в otherCableMode.content и изображения. Тест с заголовком 12 МиБ сначала падал на старом коде, после исправления проходит.

Важно: ограничение 8 МиБ относилось именно к OPC3. Для старого OPC2 использовался другой путь чтения, поэтому нельзя объявлять этот дефект доказанной причиной отказа исходного старого файла. Добавлены отдельные проверки OPC2 с большим заголовком и полным содержимым больше 25 МиБ; они проходят.

Изменения:
- Заголовок OPC3 читается блоками в StringBuilder, с проверкой бюджета до добавления блока. Вместо отдельного лимита 8 МиБ используется MaxDecodedBytes (256 МиБ — существующий бюджет полного декодера). Полное распаковывание по-прежнему ограничено 256 МиБ байтов.
- Проверка HMAC остаётся до распаковки. Подменённые/обрезанные подписанные файлы не принимаются, старые OPC2 и unsigned legacy продолжают читаться.
- Ошибка чтения заголовка теперь различает envelope/HMAC и base64/gzip/UTF-8/бюджет. Она не заявляет, что пользователь обязательно редактировал файл.
- Чтение не перезаписывает исходный файл. Транзакции записи, pending/bak, импорт и восстановление не изменены.

## Локальная диагностика без передачи сейва

`python tools/build_save_diagnostics.py` собирает `artifacts/Save-diagnostics.zip` (нужен Mono mcs).

На Windows с .NET Framework 4.x:
1. Распаковать архив в отдельную доступную для записи папку.
2. Перетащить один файл `.opc`/`.pc` на `Diagnose-save.cmd`.
3. Прислать только открывшийся `save-diagnostics.txt`.

Программа собрана из **того же SaveUtility.cs**, который используется игрой. Она сообщает размер, формат, результат подписи/декодирования, размер заголовка, безопасную строку версии, результат разбора JSON миров и число предметов. Не выводит имя мира, пути, содержимое компьютеров, скриншоты или секреты; не обращается к сети. Проверка JSON отдельным .NET-парсером не заменяет Unity JsonUtility/Newtonsoft и не воссоздаёт prefab/ISave/Lua-состояние.

Подписанная оболочка и корректный JSON ещё не доказывают, что Unity восстановит все объекты. Если диагностика проходит, а игра всё равно не открывает файл, следующий нужный материал — ошибка из Player.log при этой попытке, без отправки всего сейва.

EXE не подписан сертификатом: нельзя просить пользователя отключать Windows-защиту. При блокировке есть исходники/сборочный скрипт либо обычный Player.log.

## Проверки и ограничения

- `test_mobile_aspect_panel.py`: компиляция реальных MobileAdaptiveSlidePanel/MobileCustomizeManager и 3615 проверок на UI/TRS-дублях: 4 края, 3 угловых режима, 5 t, 5 размеров, вложенные преобразования, открытие/закрытие, смена размеров, отсутствие повторного shrink и перестройки неподвижного кадра; сравнение размеров всех 8 кнопок Menu/Main.
- `test_save_compression.py`: реальные SaveUtility/DataLoader; Unicode, OPC3, подпись, OPC2/legacy, заголовок 12 МиБ и большой OPC2 >25 МиБ, read-only/приватность отчёта.
- `test_save_diagnostics.py`: отдельный EXE, реальные modern/old/broken файлы, неизменность SHA-256 входа и отсутствие частных данных в отчёте.
- Дополнительно проверены mobile grid/layout/Android source guards, save startup/durability (15 + 4 restart), async menu (7), экспорт, screenshot state (28), Android Open with, resolution (29), picker (7), desktop picker на Win/Mac/Linux, motion blur integration (63), движение (14), 4 simple shader passes и boot guards.

Unity Editor/APK/реального телефона здесь нет. Не измерялись FPS, раскладка на настоящем EventSystem и реальный файл пользователя. Официальный motion blur и недавние исправления разрешения/пикера не заменялись. Нужен smoke-test на устройстве: соотношение превью, четыре края/угла, смена разрешения, открыть/закрыть, сохранить → зайти в игру → снова настройки. Отдельно открыть старый сейв на ПК и телефоне.
